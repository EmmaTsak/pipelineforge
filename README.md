
# PipelineForge

**Local-First DevOps & CI/CD Engineering Platform**

PipelineForge is a portfolio and learning project
exploring DevOps automation, release engineering,
and application reliability through a simulated
communication-site monitoring service.

## Goals

- Build and test a Java Spring Boot application.
- Manage development using Git branches and PRs.
- Automate builds and testing through Jenkins.
- Containerize services using Docker.
- Introduce static analysis and artifact management.
- Implement monitoring and deployment recovery.

## Technology Stack

Java | Spring Boot | Gradle | MySQL | Docker |
Jenkins | Groovy | Python | Bash | SonarQube |
Artifactory | Prometheus | Grafana

## Development Environment

All application and infrastructure services run
locally. GitHub hosts the source code and
development history.
